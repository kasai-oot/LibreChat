## ユーザー種別

| 種別 | 説明 | アクセス範囲 |
|------|------|------------|
| **管理者** | hidekasai（運営担当） | 全機能・管理画面・ユーザー管理 |
| **内部ユーザー** | kasai組織のメンバー | 全AIエージェント機能 |
| **クライアントユーザー** | X3Dクライアント等 | 割り当てられたエンドポイントのみ |

## アカウント管理フロー

### 新規ユーザー追加

```
1. hidekasaiが招待メール送信（LibreChat管理画面）
2. ユーザーが登録完了
3. 適切な役割（Role）を割り当て
4. アクセス可能なエンドポイントを設定
```

### ユーザー削除・停止

```
1. LibreChat管理画面でアカウントを無効化
2. 必要に応じてデータを削除
3. このドキュメントのユーザー台帳を更新
```
