# LibreChat カスタマイズ差分管理

> アップストリームからの独自変更を記録・管理するドキュメント

## 目的

アップストリーム同期時のコンフリクト回避と、カスタマイズ意図の保存のため、全ての独自変更をここで管理する。

## 現在のカスタマイズ一覧

### 1. librechat.yaml — X3D-Agents向け設定

| 項目 | 内容 |
|------|------|
| ファイル | `librechat.yaml` |
| 変更内容 | X3D-Agents向けのエンドポイント・モデル設定 |
| 変更理由 | X3Dクライアント向けカスタムAIエージェント提供 |
| 同期時の注意 | アップストリームの `librechat.yaml.example` と差分確認が必要 |

### 2. Dockerfile — Railway向け調整

| 項目 | 内容 |
|------|------|
| ファイル | `Dockerfile` |
| 変更内容 | Railwayデプロイ向けの環境変数・ポート設定 |
| 変更理由 | Railway PaaS環境への最適化 |
| 同期時の注意 | アップストリームのDockerfile変更を手動マージ |

### 3. Bedrock 東京リージョン設定

| 項目 | 内容 |
|------|------|
| 対象 | AWS Bedrock エンドポイント設定 |
| 変更内容 | ap-northeast-1（東京）リージョン指定 |
| 変更理由 | 日本ユーザー向けレイテンシ最適化 |
| 同期時の注意 | アップストリームのBedrock設定変更を確認 |

### 4. 独自法的文書

| 項目 | 内容 |
|------|------|
| ファイル | `config/x3d-policy.md`, `config/x3d-tos.md` |
| 変更内容 | X3D向けプライバシーポリシー・利用規約 |
| 変更理由 | 日本法・X3Dブランド向け法的文書 |
| 同期時の注意 | アップストリームに存在しないファイルのため衝突なし |

## カスタマイズ変更時のルール

1. このドキュメントを必ず更新する
2. 変更理由を明記する（将来の自分や他の担当者への引き継ぎ）
3. アップストリーム同期時のリスクを評価して記載する
4. 大きな変更はブランチを切ってPRでレビュー

## アップストリーム同期時のチェックリスト

- [ ] `librechat.yaml` の差分確認
- [ ] `Dockerfile` の差分確認
- [ ] Bedrock設定の差分確認
- [ ] 独自法的文書の影響確認
- [ ] 動作確認（ステージング環境でテスト）
